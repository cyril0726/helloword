# HelloWord

Projet web avec :

- Frontend : Vue.js + Vite
    src/
    ├── assets        → fichiers statiques
    ├── components    → petits morceaux UI
    ├── views         → pages complètes
    ├── router        → navigation URL
    ├── App.vue       → structure globale
    ├── main.ts       → démarrage app
    └── style.css     → styles globaux

- Backend : Cloudflare Workers API

- Déploiement : Cloudflare Pages + Workers
